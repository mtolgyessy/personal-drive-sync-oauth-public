PERSONAL-USE APPLICATION

Simple, private Google Drive synchronization.

Personal Drive Sync is a personal-use OAuth configuration for rclone, a command-line file synchronization tool. It connects an authorized Google Drive account with files on a local computer.

What it does

With the account owner's authorization, rclone can list, read, upload, update, and, when explicitly configured, delete files in Google Drive as part of a synchronization workflow.

The synchronization runs on the owner's own computer. This website is informational only: it does not sign users in, host files, or provide a public synchronization service.

Data and permissions

Google Drive permissions are requested solely to perform the synchronization configured by the account owner. Google Drive content is not collected by this website. For information about data access, storage, sharing, and retention, read the privacy policy.
