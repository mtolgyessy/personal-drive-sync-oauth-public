PRIVACY POLICY

How data is handled.

Personal Drive Sync is a personal-use OAuth configuration that enables the account owner to use rclone to synchronize files between a local computer and Google Drive. This website only explains that configuration.

Google data accessed

Depending on the account owner's rclone configuration and the OAuth permission granted, the tool can access Google Drive file names, metadata and contents, and can list, download, upload, modify or delete Drive files as needed for synchronization.

Purpose and use

Google Drive access is used only for the account owner's chosen file synchronization, backup and file management operations. The website itself has no login, does not request OAuth access, and does not receive or process Drive file content.

Storage and sharing

Synchronized file data resides on the owner's local storage and in their authorized Google Drive account, according to the configured operations. OAuth credentials and any local logs are handled in the owner's local rclone environment. No separate application-operated cloud service is used to receive or sell the owner's Google Drive data. Google processes information as part of providing Google Drive; GitHub hosts this public informational website and may process visitor connection information under its own policies.

Retention and control

The account owner controls local files, Google Drive files and the synchronization configuration. Retention follows the owner's storage and backup settings. Google account access can be revoked through Google Account security settings; local rclone credentials can also be removed by the owner. This informational website does not retain Google Drive user content.

Security

Google OAuth authorization is used to grant access. Access tokens and refresh tokens are not published on this website. The owner is responsible for protecting the local system and rclone configuration.

Contact and updates

For questions about this private-use configuration, use the support contact provided on its Google OAuth consent screen. This privacy notice may be updated when the configuration or its data practices change.
